# e-plantShopping

- AboutUs.jsx,
- App.css,
- App.jsx,
- CartSlice.jsx,
- ProductList.jsx,
- CartItem.jsx

Paradise Nursery is a small online plant shop I built with React and Redux Toolkit.

You can browse houseplants in different categories, add them to a cart, change quantities, delete items, and see the total update as you go. The cart icon in the navbar shows how many plants you have picked.

## Built with

- React (Vite)
- Redux Toolkit

## Run it locally

```bash
npm install
npm run dev
```
